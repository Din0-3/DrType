# DrType 自動完成 + 快捷片語
每次在診間打字的時候恨不得自己英打超快，或是又想不起那個拗口的PE該怎麼拼嗎？交給DrType!


![DrType demo](docs/demo.gif)



## 開始使用

1. 點右上角的綠色code按鈕，選download Zip 把整個資料夾下載下來並且解壓縮
2. 把 `dist` 資料夾放到一個你喜歡的地方
  - 裡面已經有預設的 `WordList.txt` 和 `Hotstrings.csv` 範例詞庫，預設是復健科門診常用詞彙，不需要額外設定就能使用，內容可以依個人需求自行修改
3. 對著 `DrType.exe`點兩下。右下角工作列會出現藍色「D」圖示
  - 如果醫院/診所電腦防毒軟體一直把DrType誤刪不給用, 可以點兩下build.bat，會在電腦上直接幫你把DrType.exe生出來，因為不是下載而是在自己生的app通常就可以避免被防毒擋的問題
4. 開始打字，打到第 2 個字母時會跳出建議
   - 如果跳出來的建議不是你要的，可以用 `↑` `↓`來移動，或是繼續打第三或第四個字母來讓選項收斂
   - 單字符合需求的話，直接按`Tab` 或是 `Enter`送出
   - 其他操作：
     - `Alt+1`～`Alt+9`：直接選第幾個
     - `Esc`：關閉
5. 登登～打難拼的單字就是這麼簡單
6. 個人化： **點一下工作列的 D 圖示**，可以打開詞庫、片語和設定視窗，讓程式更貼近你的需求

> 第一次執行時，Windows 可能跳出「Windows 已保護您的電腦」。按「其他資訊」→「仍要執行」即可。

## 開關

- **Alt+Q**：可以 **暫停／恢復** 功能（快捷鍵可以在「設定」頁改）
- 暫停時圖示會變成灰色，滑鼠旁也會短暫顯示目前狀態
- 也可以在圖示上按右鍵 →「暫停」

## 詞庫

在「詞庫」頁：
- 上方框框打字：可即時搜尋；按 **Enter** 直接加入詞庫
- 雙擊：修改。Delete：刪除。「批次加入」：一次貼上很多詞（一行一個）
- 越前面的詞，建議時越優先（可用「上移／下移」調整）
- 片語中間的字也找得到：打 `pat` 會出現 `fibrillar pattern`
- 跳字也找得到：打 `tdn` 會出現 `tendon`

詞庫就是同資料夾的 `WordList.txt`，一行一個詞，也可以用記事本直接編輯。

## 快捷片語（Hotstring）

給喜歡自己客制快捷鍵的愛好者，只要打出一個簡單的字碼組合，就可以直接展開成你設定好的一串模版！

在「快捷片語」頁按「＋ 新增片語」：
- **縮寫**：例如 `jjdd`
- **內容**：要打出來的文字，可以多行（換行 = 按 Enter）
- 用上方的按鈕插入特殊功能，不用背語法：

| 按鈕 | 語法 | 效果 |
|---|---|---|
| 日期 | `{date:yyyy/MM/dd}` | 2026/10/22 |
| 日期（民國） | `{rocdate}` | 115/10/22 |
| 時間 | `{time:HH:mm}` | 09:05 |
| Enter / Tab | `{Enter}` `{Tab}` | 按一下該鍵；`{Tab 3}` = 按三下 |
| 游標停這裡 | `{cursor}` | 展開後游標移到這個位置 |
| 剪貼簿 | `{clipboard}` | 貼上剪貼簿裡的文字 |
| 暫停 | `{wait:100}` | 等 0.1 秒（給反應比較慢的系統） |
| 其他按鍵 | `{Ctrl+A}` `{Up}` `{Del}`… | 按組合鍵 |

下方的「預覽」會即時顯示展開後的樣子。

觸發方式：
- **打完縮寫立即展開**
- **縮寫後按空白／Enter／Tab 才展開**：適合縮寫可能出現在一般單字裡的情況

片語存在 `Hotstrings.csv`，可以直接用 Excel 開啟、編輯。

## 同步／分享給同事

**最簡單**：把整個資料夾（`DrType.exe`、`WordList.txt`、`Hotstrings.csv`）複製給對方或是裝到另一台電腦。

程式內建同步的功能，可以是任何 `.txt` / `.csv` 檔案，或是google doc，google sheet 網址，只要設定公開權限就可以讀的到，方便跨不同院所都能記得你的詞庫偏好

- **合併**（建議）：加入來源的新詞，保留自己加的
- **取代**：完全以來源為準，會先自動備份到 `backup` 資料夾


## 如果遇到問題

- **某個程式打出來的字怪怪的**：「設定」→「輸出方式」改成「模擬鍵盤按鍵」或「剪貼簿貼上」
- **某個程式完全不想要它**：「設定」→「不要啟用的程式」填入程式檔名（例如 `game.exe`）
- **以系統管理員身分執行的程式沒反應**：Windows 限制一般程式不能輸入到管理員程式。請對 DrType.exe 按右鍵 →「以系統管理員身分執行」
- **突然沒反應**：按兩次 Alt+Q（關再開），會重新掛上鍵盤攔截
- 程式錯誤會記錄在同資料夾的 `error.log`
