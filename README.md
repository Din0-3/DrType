# DrType 自動完成 + 快捷片語

取代舊的 AHK Autocomplete。單一個 `DrType.exe`，免安裝，Windows 10 / 11 直接執行。

## 開始使用

1. 把 `dist` 資料夾整個複製到電腦上（例如 `D:\DrType`）
2. 雙擊 `DrType.exe`。右下角工作列會出現藍色「D」圖示
3. 開始打字，打到第 2 個字母時會跳出建議
   - `Tab` / `Enter`：選取
   - `↑` `↓`：移動
   - `Alt+1`～`Alt+9`：直接選第幾個
   - `Esc`：關閉
4. **點一下工作列的 D 圖示**，可以打開詞庫、片語和設定視窗

> 第一次執行時，Windows 可能跳出「Windows 已保護您的電腦」。按「其他資訊」→「仍要執行」即可。

## 開關

- **Alt+Q**：暫停／恢復（快捷鍵可以在「設定」頁改）
- 暫停時圖示會變成灰色，滑鼠旁也會短暫顯示目前狀態
- 也可以在圖示上按右鍵 →「暫停」

## 詞庫

在「詞庫」頁：
- 上方框框打字：可即時搜尋；按 **Enter** 直接加入詞庫
- 雙擊：修改。Delete：刪除。「批次加入」：一次貼上很多詞（一行一個）
- 越前面的詞，建議時越優先（可用「上移／下移」調整）
- 片語中間的字也找得到：打 `pat` 會出現 `fibrillar pattern`
- 跳字也找得到：打 `tdn` 會出現 `tendon`

詞庫就是同資料夾的 `WordList.txt`，一行一個詞，也可以用記事本直接編輯。

## 快捷片語（Hotstring）

在「快捷片語」頁按「＋ 新增片語」：
- **縮寫**：例如 `jjdt`
- **內容**：要打出來的文字，可以多行（換行 = 按 Enter）
- 用上方的按鈕插入特殊功能，不用背語法：

| 按鈕 | 語法 | 效果 |
|---|---|---|
| 日期 | `{date:yyyy/MM/dd}` | 2026/10/22 |
| 日期（民國） | `{rocdate}` | 115/10/22 |
| 時間 | `{time:HH:mm}` | 09:05 |
| Enter / Tab | `{Enter}` `{Tab}` | 按一下該鍵；`{Tab 3}` = 按三下 |
| 游標停這裡 | `{cursor}` | 展開後游標移到這個位置 |
| 剪貼簿 | `{clipboard}` | 貼上剪貼簿裡的文字 |
| 暫停 | `{wait:100}` | 等 0.1 秒（給反應比較慢的系統） |
| 其他按鍵 | `{Ctrl+A}` `{Up}` `{Del}`… | 按組合鍵 |

下方的「預覽」會即時顯示展開後的樣子。

觸發方式：
- **打完縮寫立即展開**（同舊版 `:*?:`）
- **縮寫後按空白／Enter／Tab 才展開**：適合縮寫可能出現在一般單字裡的情況

片語存在 `Hotstrings.csv`，可以直接用 Excel 開啟、編輯。

## 同步／分享給同事

**最簡單**：把整個資料夾（`DrType.exe`、`WordList.txt`、`Hotstrings.csv`）複製給對方。

**多台電腦用同一份**（「同步與分享」頁）：
1. 把詞庫放在 Google 試算表（A 欄一格一個詞），右上「共用」→「知道連結的任何人」可檢視
2. 把網址貼到「詞庫來源」，按「立即同步」
3. 片語也一樣，試算表欄位：`縮寫 | 內容 | 說明 | 觸發`
4. 勾選「每次啟動程式時自動同步」

來源也可以是任何 `.txt` / `.csv` 網址，或診所共用資料夾的檔案（例如 `\\server\共用\WordList.txt`）。

- **合併**（建議）：加入來源的新詞，保留自己加的
- **取代**：完全以來源為準，會先自動備份到 `backup` 資料夾

## 跟舊版 AHK 的差別

| | 舊版 AHK | DrType |
|---|---|---|
| 輸出文字 | 剪貼簿貼上（會蓋掉剪貼簿） | 直接輸入 Unicode 字元，不經過剪貼簿、也不受注音輸入法影響 |
| 注音中文模式 | 一樣會跳建議、干擾選字 | 自動停用，切回英文才作用 |
| 新增詞／片語 | 改程式碼或文字檔 | 圖形介面，即時生效 |
| 打完整的詞再按 Enter | 可能被換成較長的詞（with → without） | 照常換行 |
| 開關 | 只能結束程式（Alt+Q） | Alt+Q 暫停／恢復 |

舊的 `WordList.txt`（Big5 編碼）可以直接沿用，程式會自動辨識；存檔後會轉成 UTF-8。

**沒有移植的部分**：`jjbw`、`jjibu` 兩個計算視窗，以及 helper 的 F6–F9、Alt+F 等功能。如果還需要，可以繼續執行舊的 `autocomplete_helper.ahk`。記得先把裡面已經搬過來的片語（jjdt、jjdd、jjap、jjdel、jjreport、jj1）刪掉，以免重複觸發。

## 如果遇到問題

- **某個程式打出來的字怪怪的**：「設定」→「輸出方式」改成「模擬鍵盤按鍵」或「剪貼簿貼上」
- **某個程式完全不想要它**：「設定」→「不要啟用的程式」填入程式檔名（例如 `game.exe`）
- **以系統管理員身分執行的程式沒反應**：Windows 限制一般程式不能輸入到管理員程式。請對 DrType.exe 按右鍵 →「以系統管理員身分執行」
- **突然沒反應**：按兩次 Alt+Q（關再開），會重新掛上鍵盤攔截
- 程式錯誤會記錄在同資料夾的 `error.log`

## 自己重新編譯

不需要安裝任何東西：在 Windows 上雙擊 `build.bat`，會用 Windows 內建的 C# 編譯器產生 `dist\DrType.exe`。
（有安裝 .NET SDK 的話也可以用 `dotnet build -c Release`。）

原始碼都在 `src`：
- `KeyboardEngine.cs`：鍵盤攔截（獨立的高優先權執行緒，只做最少的工作，保證打字順暢）
- `InputSender.cs`：送出文字
- `WordList.cs`：詞庫比對
- `Expansion.cs`：片語語法
- `SettingsForm.cs`：設定視窗
